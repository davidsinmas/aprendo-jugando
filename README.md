# Aprendo Jugando

Aplicación web educativa para sesiones cortas de verano en móvil y tablet.

## Publicación

La rama `main` se publica automáticamente mediante GitHub Pages.  
Después de cada cambio confirmado en `main`, la web se actualiza sin subir archivos a servicios externos.

## Estructura

```text
index.html
version.json
css/
js/
datos/
assets/
.github/workflows/pages.yml
```

## Forma fija de actualizar

1. Sustituir los archivos modificados.
2. Crear un commit con el número de versión.
3. Subir los cambios a GitHub.
4. Revisar la publicación automática en GitHub Pages.

## Progreso del jugador

El progreso se guarda en el navegador mediante almacenamiento local. Mantener la misma URL conserva normalmente los datos. Antes de cambios importantes se recomienda usar la opción de exportar progreso de la aplicación.

## Versión base oficial

`2.0.0-base`
