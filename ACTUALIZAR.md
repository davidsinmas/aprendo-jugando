# Actualización sencilla

Para cada nueva versión:

1. Descomprime el ZIP completo que te entregue ChatGPT.
2. Copia TODO su contenido dentro de tu carpeta local `aprendo-jugando`.
3. Acepta reemplazar los archivos existentes.
4. Abre GitHub Desktop.
5. `Commit to main`.
6. `Push origin`.

GitHub solo subirá realmente los archivos que hayan cambiado.

No borres manualmente el almacenamiento del navegador: el progreso del jugador se guarda localmente.
