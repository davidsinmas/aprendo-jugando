# Historial de cambios

## 2.3.0 — 2026-08-07

- La tienda deja de usar el equipamiento dibujado antiguo.
- El avatar usa `assets/avatar/base/avatar_base.png`.
- Se integran los PNG del Caballero Espacial Común.
- Nuevas ranuras: casco, pecho, guantes, cinturón, pierneras, botas, capa, arma y escudo.
- Recompensas de nivel actualizadas al nuevo catálogo.
- Migración del almacenamiento a esquema 7.

## 2.2.0 — 2026-08-07

- Equipaciones y accesorios visualmente más realistas y espectaculares.
- Armas y escudo rediseñados.
- Control manual de diamantes en Zona de padres.
- Sin cambios en la lógica de juegos ni guardado.

## 2.1.0 — 2026-08-07

- Renovación visual de la pantalla principal.
- Avatar con más detalle, volumen, ropa y accesorios dibujados.
- Espada, bastón, espada de energía y escudo representados sin emojis.
- Tienda con tarjetas más visuales y vista previa mejorada.
- Nuevas tarjetas para los juegos.
- Se mantiene intacto el esquema de progreso y guardado.

## 2.0.0-base — 2026-08-06

- Primera base oficial para GitHub.
- Estructura modular estable.
- Publicación automática con GitHub Pages.
- Conservación del esquema de datos de las versiones anteriores.
- Preparación para actualizaciones mediante commits y pull requests.
